# Skills and analytics

The skills page is a searchable capability matrix. The technology inventory is grouped by its declared category and rendered as ruled rows rather than cards: each row carries the technology name, a usage marker with text (`Professional use` or `Learning` — never colour alone), a derived public-project count, and links to the public case studies that tag it.

The page reads the selected category from `?category=`. Search matches technology names, category labels, and related project titles. The sticky summary band, category chips, and result count are all driven by the same inventory; no number is typed.

The row language is intentionally quiet: a technology with no public project shows `No selected public project linked yet.` rather than an empty card, so sparse inventory does not read as a failure. Learning technologies carry an amber outline marker; professional use carries a solid primary marker.

The coverage chart is shared with the overview and receives server-derived public data, keeping hidden project records out of its client bundle. On this page it sits in an asymmetric evidence band: explanatory copy and the derived sample size on the left, the chart card on the right. Counts show project usage, not proficiency.
